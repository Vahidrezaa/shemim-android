# server/ — تغییرات سمت هاست

طبق سند ۰۵، کل تغییرات سرور فقط ۵ فایل است:

1. `api/fcm.php` (جدید) — ثبت/حذف توکن FCM
2. `api/push.php` (جدید) — ارسال پوش از سمت سرور
3. قلاب ارسال پوش در فایل‌های عملیات نوشتنی (چند خط)
4. اکشن `appConfig` (بررسی نسخهٔ اپ)
5. فایل کلیدها (بدون کامیت در این ریپو)

این فایل‌ها در فاز ۵ (WP-5.3) اینجا قرار می‌گیرند و شما روی هاست کپی می‌کنید.
**تا آن موقع این پوشه عمداً خالی است — منطق فعلی وب دست نمی‌خورد (اصل ۲ سند ۰۰).**
